# Action 数据库维护

- `create/kunling_action_schema.sql` 是当前全新建库基线，只用于空数据库建表。
- 已有数据库禁止执行 CREATE 基线覆盖，必须执行 `alter/` 中尚未应用的人工增量脚本。
- 当前已部署的动态 Action 旧结构直接执行
  `alter/20260831_01_simplify_action_composition.sql`，不要先执行 20260825、20260826。
  该脚本会在严格校验源结构和活动执行后重建 Action 定义、执行事件和执行记录，
  删除参数集表且不转换旧配置；异常映射规则会保留。
- 如果旧版 `_01` 已经执行中断，表现为参数集表已删除、定义表部分变更而执行表仍为旧结构，
  禁止重跑 `_01`；必须先确认相关表为空，再执行
  `alter/20260831_02_repair_partial_action_composition.sql`。
- 数据库迁移不代表运行时兼容：项目不保留旧 DTO、旧字段解析、双写或协议转换器。
- 应用启动不建表、不改表、不写入种子数据；本项目不引入 Flyway。
- 历史 ALTER 脚本执行后不得修改；后续结构变更必须继续新增按时间排序的脚本。
- 每次执行前必须备份、停止 Action 写入、核对目标库，并记录环境、操作人和执行结果。
